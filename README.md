# World History Speed Master

DAY1〜30を「次へ」「前へ」で読む日本語の世界史学習サイトです。GitHub Pagesで動く静的HTML・CSS・JavaScriptで、ビルドツールや外部ライブラリは不要です。

## 学習機能

- 全30DAYの解説カード・確認問題・DAY別まとめ
- DAY一覧、本文の用語検索、DAY内の目次
- 同じブラウザでの続きから再開と完了記録
- 「あとで復習」ブックマーク
- 文字サイズの切り替え
- 学習記録のJSONエクスポート／インポート

## 内容の範囲と出典

ユーザー提供『世界史スピマ 2.pdf』のDAY1〜30（PDF 1〜60ページ）のSummaryを参照して作成した、非公式の学習用要点整理です。DAY番号と主要な節の順序を保ち、個々の小項目は読みやすいカードへ再構成しています。確認問題は各カードから作成したものです。

教材の全語句の網羅や逐語的な再現を目的としていません。原本PDF・ページ画像・本文の転載は含みません。各DAYの画面下に参照ページを記載しています。DAY30も教材が収録した時点までの歴史を扱い、現在の政権・情勢を説明するものではありません。

## データとファイル

- `index.html`: 全30DAY共通の入口
- `study.css`: スマートフォン・タブレット・PC向けのレイアウト
- `study.js`: 読書画面、検索、学習記録など
- `content/days01-05.js` 〜 `content/days26-30.js`: 5DAYずつの学習内容
- `day27.html`: 以前のDAY27試作版。元のURLを維持するため残しています
- `.nojekyll`: 静的ファイルをそのまま配信

カードは `[主要節, 見出し, 要点, 本文, 確認問題, 答え]` の6文字列で構成します。本文の段落区切りは `\n\n` です。DAYのまとめはカードの見出しと要点から自動生成します。

## 学習記録

新しい学習画面ではlocalStorageの `whsm-course-v1` を利用します。記録は端末内のブラウザに保存され、サーバーや第三者に送信しません。端末間の自動同期はありません。ブラウザデータの削除やプライベートブラウズによって失われる場合があります。

「表示済み」は開いた解説カード数を表し、理解度を判定するものではありません。「DAY完了」は各DAYのまとめから完了ボタンを押したときに記録します。試作版からの引き継ぎは同じサイト・同じブラウザに旧記録がある場合に限ります。

JSONの読み込みは現在の記録を置き換えます。読み込む前に確認を表示し、DAY番号・カード番号・データ形式を検証します。公開サイトなので、個人情報・認証情報・非公開の教材をリポジトリへ追加しないでください。

## ローカル動作確認

リポジトリのフォルダーで、例えば `python -m http.server 8000` を起動し、ブラウザからローカルのサーバーを開きます。アプリ内の遷移はハッシュURLを使用するため、GitHub Pagesのプロジェクト用サブディレクトリでも動作します。

公開元は `main` ブランチのルートです。GitHub Pagesのビルド・公開状況はリポジトリのActionsで確認できます。
